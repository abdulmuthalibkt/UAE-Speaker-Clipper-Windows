UAE Speaker Clipper — Windows Build

This folder is prepared for a standalone Windows build.

The resource user does NOT need Python, PySide6, FFmpeg, or yt-dlp installed.
GitHub Actions builds the Windows executable and Inno Setup creates the installer.

Build steps:
1. Upload this folder to a GitHub repository.
2. Open Actions → Build Windows Installer.
3. Click Run workflow.
4. Download the artifact named UAE-Speaker-Clipper-Windows-Installer.
5. Share UAE_Speaker_Clipper_Setup.exe with Windows resources.
